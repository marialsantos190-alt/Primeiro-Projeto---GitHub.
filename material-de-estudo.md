# Material de Estudo - Versionamento com GitHub

## 1. Versionamento
É o processo de registrar as alterações realizadas em um projeto, permitindo acompanhar seu histórico.

## 2. Repositório
É o local onde ficam armazenados os arquivos e o histórico de versões de um projeto.

## 3. Commit
É um registro de uma alteração realizada no projeto, permitindo identificar o que foi modificado.

## 4. Branch
É uma ramificação do projeto que permite desenvolver alterações separadamente da versão principal.

## 5. Pull Request
É uma proposta de alteração que pode ser revisada antes de ser integrada ao projeto principal.
